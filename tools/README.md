# 🛠️ أدوات مركز القيادة

| الأداة | وظيفتها | الاستخدام |
|---|---|---|
| `inventory-scan.py` | ماسح الجرد (قراءة فقط): يعيد تصوير كل المستودعات — مستندات، مهارات، ملفات env، workflows — ويحفظ نسخة بتاريخ اليوم في `data/` للمقارنة الزمنية | `export GH_TOKEN=... && python3 tools/inventory-scan.py` |

**قاعدة:** الأدوات هنا للمدير فقط وكلها read-only افتراضياً. أدوات الكتابة (تنظيف/مزامنة) تُنفَّذ لمرة واحدة عبر جلسة المركز وتُوثَّق في `reports/` بدل إبقائها.
**دورة الاستخدام:** شغّل الماسح أسبوعياً أو بعد أي موجة عمل كبيرة، وقارن الناتج باللقطة السابقة لتحديث لوحة التحكم.
