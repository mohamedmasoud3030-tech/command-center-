## الحدود والتسليم
- طلب المالك وحدود التفويض:
- أثر خارجي (نشر / قاعدة بيانات / حسابات): لا يوجد، أو اذكر الدليل.
- كود منتج خارج نطاق المركز: لا يوجد، أو اذكر التفويض الصريح.
- العمل غير المرسل:
- رابط PR وحالته (مقترح / Draft / مفتوح / مدموج):
- قرارات المالك المتبقية والتوصية:
- نقطة الاستئناف: الملف والبند وأول أمر.
- حالة حجز الجلسة: انتظار مراجعة / تسليم / مستمر؛ لا تسقط ملكية جلسة أخرى.
