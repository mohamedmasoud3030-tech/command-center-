## Lifecycle evidence

1. **Intake:** request and authorization recorded.
2. **Verify:** upstream/default branch/PR/checks and base SHA observed.
3. **Select skills:** trigger, path, and expected evidence written.
4. **Implement:** independent branch; overlap and secrets checked.
5. **Review:** diff, tests, validator, and unresolved gaps classified.
6. **Handoff:** PR state, acceptance decision, owner decision, and resume command recorded.

> An open branch or PR is unfinished work, not proof of an active session. A
> missing/skipped check is `NOT VERIFIED`, not a pass.
